# 🧪 Variable Laboratory Bot

Інтерактивний освітній Telegram-бот, створений для вивчення базових типів даних у Python, роботи зі змінними, операцій над ними та обробки винятків (`TypeError`).

---

## 🚀 Основні можливості

* **Керування слотами змінних:** Можливість створювати, переглядати та видаляти дві незалежні змінні (`value_1` та `value_2`) без зсуву чи втрати даних.
* **Підтримка основних типів даних:** Робота з цілими числами (`int`), рядками (`str`) та булевими значеннями (`bool`).
* **Демонстрація поведінки Python:** 
  * Для `int` — виконання арифметичних операцій (додавання, віднімання, множення).
  * Для `str` — конкатенація (склеювання) рядків та демонстрація методів на кшталт `.upper()` і `.lower()`.
  * Для `bool` — логічні операції (`and`, `or`, `not`).
* **Симуляція помилок (`TypeError`):** Бот показує, як Python реагує на спробу виконати недопустимі операції між різними типами даних напряму.
* **Збереження стану:** Використання `json` для збереження даних користувачів і станів.

---

## 🛠 Технології

* **Python**
* **pyTelegramBotAPI** (`telebot`)
* **JSON** (для персистентного зберігання даних)
